# Wero1Wager — Vegas Digital

Release candidate **0.3.1-rc** para validação no Render. Dashboard demonstrativo com 24 modalidades, eventos sintéticos, endpoint /health e painel financeiro zerado.

## Render
Build: `pip install -r requirements.txt`
Start: `uvicorn app:app --host 0.0.0.0 --port $PORT`
Health: `/health`

## Segurança
Não há apostas, odds reais, depósitos, saques, afiliação de apostas ou transferência bancária. Nenhuma integração com operadores foi habilitada. A identidade gráfica final com arquivos de imagem será incorporada após upload dos assets licenciados.
